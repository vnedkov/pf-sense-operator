# pfSense API Go Client

## Open API Spec
The source of OAPI spec is at https://pfrest.org/api-docs/openapi.json
However it has an escape character before each '/' which renders it invalid for direct code generation
`openapi.json` file in this directory is generated by replacing'\/' with '/' in the original file.
```
curl -o openapi.json https://pfrest.org/api-docs/openapi.json
sed -i -e 's/\\\//\//g' openapi.json
# For Mac OS: sed -i '' -e 's/\\\//\//g' openapi.json
```

## Client generation
```
go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen -config cfg.yaml openapi.json
```
